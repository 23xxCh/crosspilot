05改代码前的安全边界

这些不是风格偏好，而是正式回填表不能破坏的业务约束。 涉及其中任何一项时，必须同步检查对应测试。

01

源采集表永远只读

所有结果只能写入运行暂存、最新结果或归档目录。

02

无产品描述必须在 API 前剔除

先删除无效商品，避免继续消耗文案、审图和生图费用。

03

问题 ID 不是通用告警

只列出因源描述为空或无产品内容而自动删除的商品。

04

正式图片必须有当前 safe 记录

风险或未知主图、变种图不能进入正式回填表。

05

主图和变种图不可直接删空

只能安全重新生成，或者隔离整个商品等待处理。

06

输出固定 13 字段并逐行对齐

任何字段调整必须同步 JSON 契约和完整流水线测试。

07

模型和 Prompt 只能统一配置

不要在业务代码中增加散落的模型名称、端点或长提示词。

08

发布必须可以回滚

继续使用完整暂存、质量验收、历史归档和原子替换。
